# 网页简介

本作品聚焦中国壮丽山河，立足给用户视觉震撼基本需求，准备了丰富照片，深入介绍了中国最具代表性的十二座名山、十四个水域景观和十二个地理区域，每个进行模糊处理，只有山的名字，当鼠标停在照片上时能自动轮播照片，并设计图片略微晃动，给用户震撼。同时，考虑到比赛本身的特殊性，我们团队加入了大量创新构思与艺术设计。深色与浅色双主题设计，适应不同使用场景和用户偏好，并可以记住用户选择，下次访问时保留上次选择。还有，首页以动态山河轮播开始，展现祖国大好河山的壮美风光。同时，有快速分类查找，点击相应板块，即可进入搜索，没有搜索到可以在留言板留言，还于主页面加入交互式中国地图，用户可点击标记在地图下方查看详细山河图片信息。当用户探索首页9个山河内容时，每个景点都配有专属的互动游戏，如用2048游戏的数字高峰象征珠穆朗玛峰的高峰，长江保护者游戏通过捡垃圾打击污染者凸显保护山河意义，连连看通过逐步消掉方块显露江南水乡图片，突出江南水乡的曲径通幽，将观赏与娱乐完美结合。为了实现丰富内容与简约界面有机结合，我们创新地将传统卡片布局改为水平轮播展示，其中，我们原创的轮播图实现方式流畅自然，富有创意。在数据展示方面，我们使用Chart.js构建了精美的数据可视化图表，直观呈现山河数据，鼠标停留或点击在相应位置还会触发相关介绍。再接着，智能搜索功能让用户快速定位感兴趣内容，考虑到祖国山河的美除了家喻户晓的名山名水，还有很多每个人心中的“家乡的山，家乡的水”，那些隐藏在祖国角落的美不能被遗忘，所以设计留言板系统促进用户交流分享，这些留言支持点赞，增加、和删除，分享他们心中的名山名水。并且对网页进行各种设备屏幕尺寸的适应，保证在各种设备的上正常运行。

注重创意，将山河展示与互动游戏深度结合，其中游戏设计充分利用原生JavaScript特性创新实现。

开始页面由山河轮播引入，背景采用渐变色彩营造山水意境，主页面交互动画流畅自然。

美术与色彩上注重色调协调搭配，基于山河主题特点，将青绿色系与深蓝底色相结合，同时在选图上别出心裁，形成和谐的色彩对比，突出焦点而避免视觉疲劳。轮播图、卡片流、网格布局等形式创意结合，增强视觉张力。

细节上，我们的鼠标停留在logo上可使logo晃动，鼠标停留在按钮上触发流水特点，点击页面最底部页脚高亮的“分享你的山河故事”直达留言板，点击小游戏跳转到小游戏网页后点击返回，返回到小游戏属于的板块，方便用户，从细节上给用户美和舒适的感受

除开形式的美学设计，功能性与内容我们也给予了相当重视，照片丰富并能表现地点特色，并添加相关介绍，在给用户带来审美体验与趣味交互的同时，真正做到了记忆地方特色，普及地理知识，激发探索祖国河山的兴趣。

最后，我们设计50题（随机抽10题）有关祖国保护山河和科普祖国山河的问答，在给用户视觉震撼后，提醒保护这些美丽山河的措施和相关适应，让这些美丽永恒。

除了以上，我们还有跳转链接，无论是导航页“点击了解更多”还是问答后的小科普，给用户更多维的视觉体验，尽可能满足用户需求

技术方面，我们立足现代Web标准，除开传统的HTML5、CSS3、JavaScript外，还使用了Chart.js数据可视化库，扎实的技术基础，保证了我们作品功能的实用与美观。
